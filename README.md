# Al Fares 
> **The First E-Commerce Platform for schools and university supplies.**

**Live Production Build:** [https://alfares-edu.netlify.app](https://alfares-edu.netlify.app)

---

## Overview
**Al Fares** is a modern web application designed to simplify the shopping experience for students. It features a responsive catalog for browsing textbooks, a real-time shopping cart system, and a secure checkout flow backed by Firebase.

### Key Features
* **User Accounts:** Secure Login/Signup via Firebase Auth.
* **Smart Search:** Real-time filtering for products.
* **Dynamic Cart:** `useCart` hook for instant global state updates.
* **Order Processing:** Full checkout simulation with Firestore database integration.
